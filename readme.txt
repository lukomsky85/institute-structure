Управление структурой образовательного учреждения с интеграцией расписания и синхронизацией с API

== Description ==

Плагин "Структура института" — это полноценное решение для управления структурой образовательного учреждения в WordPress. Плагин позволяет создавать и управлять факультетами, кафедрами, преподавателями, специальностями и расписанием занятий.

= Основные возможности: =

* 📚 **Управление факультетами** — создание, редактирование, привязка заведующих
* 🔬 **Управление кафедрами** — организация по факультетам, назначение заведующих
* 🎓 **Среднее профессиональное образование** — отдельный раздел для СПО
* 📖 **Специальности и направления** — подробная информация о программах обучения
* 👨‍🏫 **Преподавательский состав** — фото, контакты, привязка к кафедрам
* 📅 **Расписание занятий** — интеграция с внешним API, календарный вид
* 🔄 **Синхронизация с API** — автоматическое обновление данных преподавателей
* 📝 **Гибкие шорткоды** — отображение структуры на любых страницах

= Типы записей: =

* `fakultet` — факультеты
* `kafedra` — кафедры  
* `srednee_obrazovanie` — среднее профессиональное образование
* `specialnost` — специальности и направления
* `prepodavatel` — преподаватели

= Шорткоды: =

* `[institute_fakultets]` — отображение списка факультетов
* `[institute_kafedras]` — отображение списка кафедр
* `[institute_srednee]` — отображение СПО
* `[institute_specialnosti]` — отображение специальностей
* `[institute_prepodavateli]` — отображение преподавателей
* `[institute_rasp_teacher id="123"]` — расписание преподавателя

= Интеграция с API: =

Плагин поддерживает интеграцию с внешними системами расписания через настраиваемый API. Возможна автоматическая синхронизация преподавателей и расписания.

= Минималистичный дизайн: =

Все элементы интерфейса выполнены в современном минималистичном стиле с бело-черной цветовой схемой.

== Installation ==

= Установка через админку WordPress: =

1. Перейдите в раздел "Плагины" → "Добавить новый"
2. В поиске введите "Структура института"
3. Нажмите "Установить" и затем "Активировать"

= Установка вручную: =

1. Скачайте архив с плагином
2. Распакуйте архив в директорию `/wp-content/plugins/`
3. Перейдите в админку WordPress → Плагины
4. Найдите "Структура института" и нажмите "Активировать"

= После активации: =

1. Настройте параметры расписания в разделе "Настройки" → "Расписание"
2. Укажите базовый URL вашего API расписания
3. Протестируйте подключение к API
4. При необходимости синхронизируйте преподавателей через "Инструменты" → "Синхронизация преподавателей"

== Frequently Asked Questions ==

= Как настроить расписание? =

Перейдите в раздел "Настройки" → "Расписание" и укажите базовый URL вашего API расписания. Затем нажмите "Проверить подключение" для тестирования.

= Как синхронизировать преподавателей с API? =

Используйте страницу "Инструменты" → "Синхронизация преподавателей". Укажите диапазон ID для сканирования и запустите процесс синхронизации.

= Где найти шорткоды для отображения? =

Все доступные шорткоды перечислены в разделе "Описание". Используйте их на любых страницах или записях вашего сайта.

= Плагин бесплатный? =

Да, плагин полностью бесплатный и распространяется под лицензией GPL v2 или позже. Вы можете использовать его без ограничений.

= Поддерживается ли многоязычность? =

Да, плагин поддерживает локализацию. Все тексты вынесены в файл перевода.

= Как обновить плагин? =

Плагин можно обновить автоматически через админку WordPress или вручную, скачав новую версию и заменив файлы.
