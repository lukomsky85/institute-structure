Полноценное управление структурой образовательного учреждения: факультеты, кафедры, СПО, преподаватели, расписание, история изменений и гибкое разграничение доступа.

== Description ==

**Структура института** — WordPress-плагин для управления организационной структурой учебного заведения. Разработан для Омского института водного транспорта, подходит для любого вуза или колледжа.

= Основные возможности =

**Структура учреждения**

* Управление факультетами с фото декана, описанием и списком кафедр
* Управление кафедрами с фото заведующего, НМР/НРС/УВР, публикациями
* Отделения среднего профессионального образования (СПО)
* Специальности и направления подготовки
* Преподавательский состав с фото, должностью, учёной степенью

**Расписание занятий**

* Интеграция с внешним API расписания
* Календарный вид с навигацией по дням
* Компактный и детальный режим отображения
* SVG-иконки по типу занятия (лекция, практика, лаборатория, экзамен)
* Кеширование запросов к API

**Синхронизация**

* Автоматическая синхронизация преподавателей из внешнего API
* Сканирование по диапазону ID
* Пакетная синхронизация с прогресс-баром

**Управление доступом**

* Роли: «Редактор раздела» и «Менеджер структуры»
* Поддержка стандартных ролей WordPress (Автор, Редактор)
* Привязка нескольких пользователей к одному разделу
* Ограниченное меню для редакторов раздела

**История изменений**

* Автоматическая запись кто, когда и что изменил
* Лента последних изменений на странице плагина
* Полная история с пагинацией в отдельном разделе
* Детализация изменённых полей

**Интерфейс**

* Вкладки в метабоксах (Основное, Описание, НМР/НРС/УВР, Публикации, Преподаватели)
* Просмотр и открепление преподавателей прямо из метабокса кафедры
* Единое меню «Структура института» вместо разрозненных пунктов
* Страница управления доступом со сводной таблицей

= Шорткоды =

* `[fakultety]` — список факультетов
* `[kafedry]` — список кафедр
* `[srednee_obrazovanie]` — отделения СПО
* `[specialnosti]` — специальности
* `[prepodavateli kafedra="ID"]` — преподаватели (с фильтром по кафедре)
* `[prepod_rasp id="ID"]` — расписание преподавателя
* `[prepod_rasp id="ID" compact="true"]` — компактное расписание

= Публичные страницы =

Каждый раздел имеет собственную публичную страницу с вкладками:

* **Факультет** — О факультете / Кафедры / Преподаватели / Публикации
* **Кафедра** — О кафедре / НМР / Работа студентов / УВР / Преподаватели / Публикации
* **Отделение СПО** — Об отделении / Специальности / Преподаватели / Публикации
* **Преподаватель** — Профиль / Расписание занятий

== Installation ==

= Установка вручную =

1. Скачайте архив плагина
2. Распакуйте в директорию `/wp-content/plugins/institute-structure/`
3. Перейдите в Плагины → Активировать «Структура института»

= После активации =

1. Перейдите **Структура института → Настройки API**
2. Укажите базовый URL вашего API расписания
3. Нажмите «Проверить подключение»
4. При необходимости запустите **Синхронизацию** преподавателей

= Назначение доступа пользователям =

1. Назначьте пользователю роль «Редактор раздела» (или используйте «Автор»)
2. Откройте нужную кафедру/факультет в редакторе
3. В боксе «Доступ к редактированию» (справа) отметьте пользователя
4. Сохраните — пользователь получит доступ только к этому разделу

== Frequently Asked Questions ==

= Как настроить расписание? =

Перейдите **Структура института → Настройки API**, укажите базовый URL внешнего API расписания и проверьте подключение.

= Как синхронизировать преподавателей? =

Перейдите **Структура института → Синхронизация**, укажите диапазон ID и запустите процесс.

= Как дать декану доступ только к своей странице? =

Назначьте пользователю роль «Автор» или «Редактор раздела», затем откройте страницу факультета и отметьте его в боксе «Доступ к редактированию».

= Можно ли привязать несколько пользователей к одному разделу? =

Да. В боксе «Доступ к редактированию» отображается список с чекбоксами — можно выбрать любое количество пользователей.

= Где смотреть кто что изменял? =

В разделе **Структура института → История**. Также последние 5 изменений видны прямо на главной странице плагина и в метабоксе каждого раздела.

= Как открепить преподавателя от кафедры? =

На странице редактирования кафедры перейдите на вкладку «Преподаватели» — у каждой карточки есть кнопка × для открепления.

= Нужны ли дополнительные плагины? =

Нет. Плагин работает самостоятельно. Для классического редактора рекомендуется «Classic Editor» (Gutenberg отключается автоматически для CPT плагина).
